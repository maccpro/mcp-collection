# Instructions for `laravel-code-pattern` MCP Server

The `laravel-code-pattern` MCP server enforces Clean Architecture, Dependency Inversion Principle (DIP), OWASP security patterns, and multi-tenant migration standards for Laravel and PHP systems.

## Mandatory Rules for AI Agents

1. **Pre-Commit Architectural Gate (`architecture_gate`)**:
   - MUST be invoked before committing any changes to Laravel/PHP files.
   - You do NOT need to manually collect modified files; if `files` is omitted, `architecture_gate` dynamically discovers all modified and untracked `.php` files from Git.
   - In Antigravity, invoke via `call_mcp_tool`:
     ```json
     {
       "ServerName": "laravel-code-pattern",
       "ToolName": "architecture_gate",
       "Arguments": {
         "workspace_path": "<project_root>",
         "include_warnings": true
       }
     }
     ```
   - **Gate Decision:**
     - `PASS`: Proceed to Code Impact Gate (`cia_quality_gate`).
     - `BLOCK_AND_RETRY_MIMO` / `FAIL`: Immediately fix all reported violations. Do NOT commit code while the gate fails!

2. **Automated Live MiMo Refactoring (`architecture_remediate_mimo`)**:
   - When `architecture_gate` reports violations, you can immediately call `architecture_remediate_mimo` to get canonical clean architecture code generated by Xiaomi MiMo:
     ```json
     {
       "ServerName": "laravel-code-pattern",
       "ToolName": "architecture_remediate_mimo",
       "Arguments": {
         "file_path": "<path/to/violating_file.php>"
       }
     }
     ```

3. **Canonical Architecture Flow:**
   ```text
   Controller -> FormRequest -> DTO -> Action -> optional Service -> RepositoryInterface -> Repository -> Model -> Database
   ```
   - **Controllers:** Thin only. Never import or query Eloquent models or `DB::` directly.
   - **Actions:** Single-purpose `__invoke()` receiving typed DTOs or primitives. Inject `RepositoryInterface` contracts, never concrete repositories or HTTP Requests.
   - **FormRequests:** Validation and authorization only. Never perform DB persistence.
   - **DTOs:** Pure immutable value objects (`readonly`).
   - **Multi-Tenant Migrations:** Must strictly reside in `database/migrations/tenant/`.
